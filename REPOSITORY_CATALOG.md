## Advertencias

- En el README histórico de `documentation-hub` figura un total de 23 repositorios y proyecciones financieras. **No son cifras del inventario actual** y no deben tratarse como ventas realizadas.
- Los nombres o estados de archivo no bastan para confirmar que una aplicación está publicada.
- Este catálogo omite deliberadamente detalles de repositorios privados y de infraestructura.
- Antes de cambiar visibilidad hay que auditar el historial completo por secretos, permisos y propiedad intelectual.
