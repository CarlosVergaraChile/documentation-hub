# Guía de entrada al GitHub de Ingeniería de Gestión

> Estado de inventario: 12 de noviembre de 2026. Este documento organiza enlaces y responsabilidades; **no certifica que cada aplicación esté desplegada, probada o comercialmente validada**.

## Qué se encuentra aquí

Este repositorio es un **índice público**. No es el lugar para guardar el código de todos los productos, datos de clientes, expedientes de ventas ni configuraciones de Hostinger.

El perfil [CarlosVergaraChile](https://github.com/CarlosVergaraChile) tiene 48 repositorios accesibles al momento del inventario: 33 públicos, 15 privados, 20 archivados y 28 no archivados. Los repositorios archivados se conservan como historia, no como productos activos.

## Cómo interpretar el estado de un producto

- **Documentado:** existe una especificación o descripción.
- **Implementado:** existe código/artefacto inspeccionable.
- **Probado:** hay un resultado de pruebas reproducible y asociado a una versión.
- **Publicado:** una URL fue comprobada con sus recursos y versión.
- **Validado comercialmente:** existen evidencias de clientes, contratos o pilotos.

No se debe inferir una etapa a partir de otra.

## Guía mínima de contribución

1. Abrir una rama con nombre `docs/...`, `feat/...` o `fix/...`.
2. Usar un pull request para revisar cambios relevantes; evitar pushes directos a `main`.
3. Mantener un README breve con propósito, estado, instrucciones de uso y licencia si aplica.
4. Separar pruebas automáticas, datos de ejemplo y material comercial.
5. Consultar [Política de publicación](PUBLICATION_POLICY.md) antes de divulgar datos o código.

> **Nota histórica:** las cifras y proyecciones del README original de este repositorio son documentos anteriores y no constituyen una auditoría vigente. Este índice no las ratifica.
